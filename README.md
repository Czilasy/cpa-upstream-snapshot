# cpa upstream snapshot

Mirror of the public Codeberg backup of the CLIProxyAPI plugin set.

Upstream: https://codeberg.org/mingjiu/cpa-multi-plugins

This repository only stores the fetched source files so that hosts which cannot
reach Codeberg directly (HTTP 429 on the egress IP) can still read the version
lines. Nothing here is modified by hand; a scheduled workflow overwrites it.
